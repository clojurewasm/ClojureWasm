# decision, not a formality. That is the whole point of the file.
#
# Three groups, all deliberate:
#
#   1. Protocol names (ISeq, ILookup, Seqable, …). cljw has no Java, so where
#      JVM Clojure has the `clojure.lang.*` INTERFACES a deftype implements,
#      cljw has protocols (ADR-0007 Option beta / ADR-0059). They must be
#      public for `(deftype Foo [] ISeq (-first [_] :a))` to compile, exactly
#      as ClojureScript publishes `cljs.core/ISeq`.
#   2. Protocol METHOD names (-first, -count, -assoc, …). Same reason, same
#      ClojureScript convention. `test/conformance/verified_projects/
#      data.finger-tree` depends on this stack by name.
#   3. A small set of cljw-original conveniences (array?, queue?, …).
#
# The gate asserts cljw's extra-name set EQUALS this file. A name added to
# clojure.core that is not here fails the build.
